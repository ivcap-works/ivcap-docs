# Guides

Task-oriented guides for every audience. Pick the section that matches your role.

---

<div class="grid cards" markdown>

- :material-play-circle: **[Running Analyses](running/index.md)**

    For scientists, analysts, and data engineers who want to use existing
    services — discover what's available, submit jobs, retrieve results, and
    query provenance.

- :material-code-braces: **[Building Services](building/index.md)**

    For software engineers and researchers who want to wrap their code as an
    IVCAP service — from a simple lambda function to a multi-stage batch
    pipeline.

- :material-robot: **[Building AI Agents](agents/index.md)**

    For AI engineers building agentic services — LLM integration via the
    sidecar, multi-agent orchestration, CrewAI, and LlamaIndex on IVCAP.

- :material-api: **[Integrating IVCAP](integrating/index.md)**

    For application developers connecting IVCAP to their own systems — Python
    client SDK, REST API, and the CLI's built-in MCP server.

- :material-pipe: **[Argo Workflows](argo-workflows/index.md)**

    For engineers building multi-stage pipelines — Docker image build and
    push, Argo Workflow YAML, `ivcap.yml` service definition, and deployment
    to the IVCAP Argo controller.

- :material-dna: **[Nextflow Pipelines](nextflow/index.md)**

    For bioinformaticians and data scientists with existing Nextflow DSL2
    pipelines — package, deploy, and run them on IVCAP with full provenance
    tracking and no custom Docker builds required.

</div>
