    Discovering Services¶

    IVCAP services are registered analytic capabilities — each with a defined parameter schema, description, and lifecycle status. This guide covers how to discover, filter, and inspect them.

    Listing All Services¶

    The list() method returns a lazy PageIterator that fetches pages as you consume items:

    for await (const svc of client.services.list()) {
  console.log(svc.id, svc.name, svc.description);
}

    Limiting Results¶

    // Only fetch the first 10 services
for await (const svc of client.services.list({ limit: 10 })) {
  console.log(svc.name);
}

    Free-text Search¶

    // Full-text search across name and description
for await (const svc of client.services.list({ search: "fire risk" })) {
  console.log(svc.id, svc.name);
}

    Sorting¶

    for await (const svc of client.services.list({
  orderBy:   "name",
  orderDesc: false,
})) {
  console.log(svc.name);
}

    Collecting All at Once¶

    import { collectAll } from "@ivcap/client";

const allServices = await collectAll(client.services.list());
console.log(`Found ${allServices.length} services`);

    Fetching a Single Page¶

    Use listPage() when you need direct access to pagination cursors:

    const page = await client.services.listPage({ limit: 20 });
console.log(page.items.length, "services on this page");

    Getting Service Details¶

    Fetch the complete description including the parameter schema:

    const svc = await client.services.get("urn:ivcap:service:abc-123");

console.log("Name:       ", svc.name);
console.log("Description:", svc.description);
console.log("Status:     ", svc.status);   // "active" | "inactive" | "error"
console.log("Tags:       ", svc.tags);

// Inspect parameter definitions
svc.parameters.forEach(p => {
  const required = p.optional ? "" : " [required]";
  const def      = p.default  ? ` (default: ${p.default})` : "";
  console.log(`  ${p.name} : ${p.type}${required}${def}`);
  if (p.description) console.log(`    ${p.description}`);
});

    ServiceDetail Fields¶

    Field Type Description
    id URN Unique service identifier
    name string Human-friendly name
    description string What the service does
    status ServiceStatus active | inactive | error
    parameters ParameterDef[] Input parameter definitions
    tags string[] Searchable tags
    policy URN Access policy URN
    validFrom DateTimeString When the service became valid
    validTo DateTimeString Expiry time (if any)

    ParameterDef Fields¶

    Field Type Description
    name string Parameter name (used in job requests)
    type string Data type (string, artifact, number, …)
    description string Human description
    label string? UI label
    unit string? Physical unit
    optional boolean? Whether the parameter may be omitted
    default string? Default value
    options Array<{value, description}>? Allowed values (enum)

    Historical Queries¶

    Query the service catalogue as it was at a specific point in time:

    const svc = await client.services.listPage({
  atTime: "2025-01-01T00:00:00Z",
});

    Finding a Service by Name¶

    There is no dedicated "find by name" endpoint; use search + iteration:

    async function findServiceByName(
  client: IvcapClient,
  name: string,
): Promise<ServiceDetail | undefined> {
  for await (const svc of client.services.list({ search: name })) {
    if (svc.name === name) return client.services.get(svc.id);
  }
  return undefined;
}
