    Error Handling¶

    The IVCAP SDK throws typed error classes that map directly to HTTP status codes. This makes it easy to write robust, specific error handlers.

    Error Class Hierarchy¶

    Error
└── IvcapError          (base class — all IVCAP errors)
    ├── BadRequestError          (HTTP 400)
    ├── UnauthorizedError        (HTTP 401)
    ├── ForbiddenError           (HTTP 403)
    ├── NotFoundError            (HTTP 404)
    ├── ConflictError            (HTTP 409)
    ├── InvalidParameterError    (HTTP 422)
    ├── NotImplementedError      (HTTP 501)
    ├── ServiceUnavailableError  (HTTP 503)
    ├── AmbiguousResultError     (multiple matches where one expected)
    └── TimeoutError             (polling timeout — no HTTP code)

    Catching Errors¶

    Catching a Specific Error Type¶

    import {
  IvcapClient,
  NotFoundError,
  UnauthorizedError,
  TimeoutError,
  ForbiddenError,
} from "@ivcap/client";

try {
  const job = await client.jobs.get(serviceId, "urn:ivcap:job:unknown");
} catch (err) {
  if (err instanceof NotFoundError) {
    console.error("Job not found:", err.resourceId);
  } else if (err instanceof UnauthorizedError) {
    console.error("Token missing or expired — please log in again");
  } else if (err instanceof ForbiddenError) {
    console.error("Insufficient permissions:", err.message);
  } else if (err instanceof TimeoutError) {
    console.error("Polling timed out:", err.message);
  } else {
    throw err; // re-throw unknown errors
  }
}

    Catching Any IVCAP Error¶

    import { IvcapError } from "@ivcap/client";

try {
  await client.artifacts.upload(data, opts);
} catch (err) {
  if (err instanceof IvcapError) {
    console.error(`IVCAP error [${err.statusCode}]: ${err.message}`);
    console.error("Details:", err.details);
  } else {
    throw err;
  }
}

    Error Class Reference¶

    IvcapError (base class)¶

    All IVCAP errors extend this class.

    Property Type Description
    message string Human-readable error description
    statusCode number \| undefined HTTP status code (if applicable)
    details unknown Raw response body for debugging

    BadRequestError (400)¶

    The request was malformed — check your parameters.

    import { BadRequestError } from "@ivcap/client";
// err.message — what was wrong
// err.details — the full server response

    UnauthorizedError (401)¶

    The token is missing, expired, or invalid.

    import { UnauthorizedError } from "@ivcap/client";
// err.message — "Not authorized" or server message

    ForbiddenError (403)¶

    You are authenticated, but lack permission for this resource.

    import { ForbiddenError } from "@ivcap/client";
// err.message, err.details

    NotFoundError (404)¶

    The requested resource does not exist.

    import { NotFoundError } from "@ivcap/client";
// err.resourceId — the URN that wasn't found (if returned by the server)

    ConflictError (409)¶

    A resource with the same identity already exists.

    import { ConflictError } from "@ivcap/client";
// err.resourceId — the conflicting resource URN

    InvalidParameterError (422)¶

    A parameter value failed server-side validation.

    import { InvalidParameterError } from "@ivcap/client";
// err.paramName  — which parameter was invalid
// err.paramValue — the value that was rejected

    ServiceUnavailableError (503)¶

    The platform is temporarily unavailable. Implement retry with back-off.

    import { ServiceUnavailableError } from "@ivcap/client";

    TimeoutError (polling timeout)¶

    Thrown by jobs.createAndWait() or jobs.waitUntilDone() when the job doesn't complete within the configured timeout window.

    import { TimeoutError } from "@ivcap/client";

try {
  const job = await client.jobs.createAndWait(serviceId, req, {
    timeout: 30_000,  // 30 seconds
  });
} catch (err) {
  if (err instanceof TimeoutError) {
    console.error("Increase timeout or check service health");
  }
}

    Retry Patterns¶

    Simple Retry with Back-off¶

    async function withRetry<T>(
  fn: () => Promise<T>,
  maxAttempts = 3,
  delayMs = 1_000,
): Promise<T> {
  for (let attempt = 1; attempt <= maxAttempts; attempt++) {
    try {
      return await fn();
    } catch (err) {
      if (attempt === maxAttempts) throw err;
      if (err instanceof ServiceUnavailableError) {
        const wait = delayMs * 2 ** (attempt - 1);
        console.warn(`Attempt ${attempt} failed — retrying in ${wait}ms…`);
        await new Promise(r => setTimeout(r, wait));
      } else {
        throw err; // don't retry non-transient errors
      }
    }
  }
  throw new Error("unreachable");
}

// Usage
const artifact = await withRetry(() =>
  client.artifacts.upload(data, opts)
);
