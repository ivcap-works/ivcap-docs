    Working with Artifacts¶

    Artifacts are binary or structured data blobs stored on IVCAP — sensor readings, images, CSV files, trained models, or any other data. They are the primary input/output mechanism for services.

    Uploading Artifacts¶

    Upload a String or JSON¶

    const artifact = await client.artifacts.upload(
  JSON.stringify({ temperature: [21.3, 22.1, 19.8] }),
  { name: "sensor-data.json", contentType: "application/json" }
);
console.log("Created:", artifact.id, artifact.status);

    Upload a Buffer or ArrayBuffer¶

    const buffer = Buffer.from("Hello, IVCAP!");

const artifact = await client.artifacts.upload(buffer, {
  name:        "hello.txt",
  contentType: "text/plain",
});

    Upload a File (Node.js)¶

    import { createReadStream } from "fs";
import { readFile } from "fs/promises";

// Stream (memory-efficient for large files)
const artifact = await client.artifacts.upload(
  createReadStream("large-dataset.csv"),
  { name: "large-dataset.csv", contentType: "text/csv" }
);

// Buffer (simpler for small files)
const bytes = await readFile("image.png");
const img = await client.artifacts.upload(bytes, {
  name:        "image.png",
  contentType: "image/png",
});

    Upload a Blob (Browser)¶

    const file = document.querySelector<HTMLInputElement>("#file")!.files![0];
const artifact = await client.artifacts.upload(file, {
  name:        file.name,
  contentType: file.type,
});

    Upload Options¶

    Option Type Description
    name string Human-friendly name for the artifact
    contentType string MIME type (e.g. application/json, image/png)
    collection URN Assign the artifact to a named collection
    policy URN Access policy URN

    Downloading Artifacts¶

    Download as ArrayBuffer¶

    const bytes: ArrayBuffer = await client.artifacts.download("urn:ivcap:artifact:abc...");
// write to disk, process as binary, etc.

    Download as UTF-8 String¶

    const text = await client.artifacts.downloadText("urn:ivcap:artifact:abc...");
console.log(text);

    Download and Parse as JSON¶

    interface MyResult {
  score: number;
  label: string;
}

const result = await client.artifacts.downloadJson<MyResult>("urn:ivcap:artifact:abc...");
console.log(result.score, result.label);

    Listing Artifacts¶

    // Iterate all artifacts (lazy pagination)
for await (const a of client.artifacts.list()) {
  console.log(a.id, a.name, a.status, a.mimeType);
}

// With options
for await (const a of client.artifacts.list({
  limit:     50,
  orderBy:   "name",
  orderDesc: false,
})) {
  console.log(a.name);
}

    Getting Artifact Metadata¶

    const detail = await client.artifacts.get("urn:ivcap:artifact:abc...");

console.log(detail.id);
console.log(detail.name);
console.log(detail.status);       // "pending" | "partial" | "ready" | "error" | "unknown"
console.log(detail.mimeType);
console.log(detail.size);         // bytes
console.log(detail.createdAt);
console.log(detail.lastModifiedAt);
console.log(detail.dataHref);     // direct download URL (if available)

    Artifact Status Values¶

    Status Meaning
    pending Upload has started but not completed
    partial Partially uploaded (large multipart upload)
    ready Fully uploaded and available for download
    error Upload failed
    unknown Status could not be determined

    Job Products¶

    When a job succeeds, its output artifacts are listed under job.products.items:

    const job = await client.jobs.createAndWait(serviceId, req);

if (job.status === "succeeded") {
  for (const product of job.products.items) {
    console.log(product.id, product.mimeType, product.size);

    const result = await client.artifacts.downloadJson(product.id);
    console.log(result);
  }
}

    Each ProductListItem has: id, status, href, dataHref, name, mimeType, size.
